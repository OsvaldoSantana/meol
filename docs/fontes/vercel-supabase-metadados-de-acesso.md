# Vercel e Supabase — que metadados de acesso as plataformas guardam por conta própria

*Lido em 27/09/2026, para o pré-registro final do teste de marca (P-162, S5 v2). Leitura
larga feita por subagente (§5-A.10), com URL e trecho literal por afirmação. Três trechos
foram **conferidos por mim com `curl`** no mesmo dia (marcados ✔). O que ficou sem
confirmação está marcado `NAO_CONFIRMADO`.*

*Revisão de 02/10/2026 (Claude Code, sessão local): uma segunda leitura, independente, por
outro subagente, confirmou a coleta do IP pela Vercel, a retenção de 1 hora, os Drains fora do
Hobby, o Analytics desligado por padrão, os cabeçalhos do gateway do Supabase e a retenção de
1 dia. Ela achou uma linha a mais, a do painel do Firewall, cujo trecho conferi com `curl`
(✔ 02/10). As linhas do DPA e do IP para DDoS ela não leu.*

**Por que importa.** A decisão dele é "sem IP, sem nome, sem e-mail". A tabela da pesquisa
cumpre isso. Mas as duas plataformas registram metadados de acesso **sem que o dono
configure nada**, e isso vai para o consentimento, para o contrato da página (S6) e para as
limitações.

## O que decorre daqui para a página (S6)

Leitura minha, a partir das duas tabelas:

1. **O navegador não chama o Supabase.** Se chamasse, o log do gateway guardaria por 1 dia o
   IP, o user agent e a geolocalização até o CEP de cada pessoa, sem opção de desligar. A
   página grava por uma função no servidor da Vercel, que **não repassa** os cabeçalhos do
   cliente (`x-forwarded-for`, `x-real-ip`, `user-agent`).
2. **O link é o mesmo para todos**, sem identificador na URL: as duas plataformas guardam o
   caminho com a query.
3. **Web Analytics e Speed Insights ficam desligados**, e a função não escreve a resposta
   no log (`console.log`), para o conteúdo não parar no log de runtime.
4. **O que fica, e não se desliga:** a Vercel guarda o IP e o user agent de quem abre a
   página. O log visível ao dono dura 1 hora no Hobby, e o IP para DDoS dura um prazo que
   ela não publica. **O IP não entra na tabela da pesquisa, mas a plataforma o tem.** Por
   isso o consentimento promete "a pesquisa não pede nome nem e-mail", e não "sem IP".

## O que ficou sem confirmação

- se existe como desligar o log de runtime da Vercel ou o log do gateway do Supabase;
- o prazo do IP "para DDoS" da Vercel e o dos "traffic flow logs" do Supabase;
- a região física dos logs nas duas plataformas;
- a lista de subprocessadores do Supabase: a página é montada no navegador, e o HTML
  baixado não a traz.
